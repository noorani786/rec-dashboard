Missing attendance sessions (date · class with no entry)

A session is flagged only when no attendance was entered for that class on a date it was expected to meet. Expected dates use each class's own weekly cadence within its active window, are counted only when the location was in session that day, and exclude the scheduled holidays from holidays.csv. Partial sessions where some students were left unmarked are not counted here.
